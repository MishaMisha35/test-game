# ETERNAL REALMS: SHADOW OF THE ANCIENTS — 0.2.0

Играбельный трёхмерный fantasy action RPG пролог для Windows и Linux. Это **первый этап разработки с несколькими RPG-дополнениями**, а не законченная AAA-игра. Исходники, локальная физика, бой и игровой цикл реализованы в проекте. Версия **0.2.0 Ultra Smooth** добавляет интерполяцию движения, новую камеру, последовательности ударов/парирование и четыре графических пресета; [полный список изменений и настройки](docs/ULTRA-SMOOTH.md).

Основной вариант распространения — отдельное настольное приложение: игрок распаковывает архив и запускает исполняемый файл. Открывать браузер, устанавливать Node.js или запускать сервер ему не требуется. Внутри приложение использует Three.js, Rapier и Electron.

## Скачать и запустить собранную версию

Получение файлов через GitHub описано в [docs/DOWNLOADS.md](docs/DOWNLOADS.md). После локальной упаковки артефакты находятся в `release/`:

| Платформа   | Архив                                   | Запуск после полной распаковки |
| ----------- | --------------------------------------- | ------------------------------ |
| Windows x64 | `Eternal-Realms-0.2.0-Windows-x64.zip`  | `Eternal Realms.exe`           |
| Linux x64   | `Eternal-Realms-0.2.0-Linux-x64.tar.gz` | `./"Eternal Realms"`           |

Архив исходников: `release/Eternal-Realms-0.2.0-Source.zip`. Инструкция сборки находится ниже.

Сохраняйте все файлы и подпапки рядом с исполняемым файлом. Один `.exe`, скопированный из папки приложения, работать не будет. Файл `release/SHA256SUMS.txt` содержит контрольные суммы архивов. Интернет во время игры не требуется.

Нужны клавиатура, мышь, графический ускоритель с WebGL 2 и актуальный драйвер. Для Linux также необходимы графическая сессия и системные библиотеки GTK/NSS/GBM/аудио. Windows-сборка пока не подписана цифровым сертификатом. Архивы являются переносными приложениями, а не установщиками. macOS на этом этапе не поддерживается.

## Запуск из исходников

Рекомендуется **Node.js 24** и npm; текущие зависимости упаковки требуют современный Node.js. Команды выполняются из корня этого репозитория:

```sh
npm ci
npm run build
npm run desktop
```

`build` выполняет строгую проверку TypeScript и создаёт `dist/`. `desktop` открывает локальную сборку в окне Electron, поэтому сначала требуется `build`. При изменении исходников повторите сборку и перезапустите приложение. Для запуска нужен рабочий графический сеанс; одна консоль без дисплея недостаточна.

Быстрая разработка рендерера с автоматическим обновлением доступна через `npm run dev`. Это вспомогательный режим Vite; в распространяемом приложении сервера нет.

### Собрать настольные приложения

```sh
npm run package:desktop
```

Команда собирает игру и создаёт обе версии в `release/`. При первой установке и упаковке нужен доступ к npm и официальным загрузкам Electron. Подписи и контрольные суммы скачиваемых зависимостей не отключаются. Для создания ZIP и tar.gz в среде упаковки нужны команды `zip` и `tar`.

После `npm run build` можно упаковать только одну платформу:

```sh
node scripts/package-desktop.mjs win32
node scripts/package-desktop.mjs linux
```

Кросс-сборка `.exe` на Linux не подтверждает его работу на Windows: целевую платформу следует проверять отдельно. Инструкции подготовки депо и ограничения интеграции Steam приведены в [docs/STEAM.md](docs/STEAM.md). Публикация в Steam из этого проекта автоматически не выполняется.

## Как играть

Выберите **Begin journey**. Рядом с местом появления стоит Waykeeper: подойдите и нажмите `E`, чтобы получить задание. Идите на север по старой дороге, победите четыре тени и снимите защитные печати. Затем в северном святилище пробудится Fallen Guardian. Его победа завершает пролог; после этого можно продолжить исследование.

Удар наносит урон только при пересечении реальной зоны атаки с телом противника, с учётом направления, дистанции, высоты и препятствий. Красное/золотистое кольцо предупреждает об атаке врага: уходите из зоны или блокируйте. Во второй фазе Хранитель выполняет более опасный круговой удар. После смерти можно вернуться к началу долины; заработанные уровни, золото и побеждённые враги сохраняются в текущем прохождении.

| Управление                      | Действие                                              |
| ------------------------------- | ----------------------------------------------------- |
| `W A S D` / стрелки             | Перемещение относительно камеры                       |
| Удерживать ПКМ и двигать мышь   | Поворот камеры; персонаж одновременно блокирует       |
| Двойной щелчок по игровой сцене | Захват мыши для свободного поворота камеры            |
| `Z` / `C`                       | Поворот камеры с клавиатуры                           |
| `V`                             | Переключить вид от первого / третьего лица            |
| Колесо мыши                     | Дистанция камеры 2,8–10 м                             |
| `B`                             | Смена плеча камеры                                    |
| `CapsLock`                      | Переключение ходьбы                                   |
| `Shift`                         | Спринт с расходом выносливости                        |
| `Space`                         | Прыжок                                                |
| `Ctrl`                          | Медленное движение / приседание                       |
| ЛКМ или `R`                     | Лёгкая атака мечом                                    |
| `Shift` + ЛКМ / `R`             | Тяжёлая атака                                         |
| ПКМ                             | Блок; начало блока даёт окно парирования 0,16 с       |
| `Q`                             | Рывок-уклонение с краткой неуязвимостью               |
| `1` / `2`                       | Выбрать Ember Bolt / Frost Lance                      |
| `F`                             | Выпустить выбранное атакующее заклинание              |
| `3`                             | Сразу применить Mending Light: лечение за 30 маны     |
| `H`                             | Выпить лечебное зелье                                 |
| `E`                             | Поговорить, открыть сундук или активировать святилище |
| `I` / `K` / `M` / `J`           | Инвентарь / навыки / карта / журнал                   |
| `Esc`                           | Закрыть окно, поставить игру на паузу или продолжить  |
| `F5`                            | Сохранить прогресс                                    |
| `F11`                           | Полноэкранный режим в настольном приложении           |

`R` здесь — альтернативная кнопка атаки, а не смена оружия. Кнопки панели способностей отображают подсказки управления; конкретные способности вызываются указанными клавишами. Карта, журнал, настройки и другие открытые панели приостанавливают симуляцию.

## Что реализовано

- Трёхмерная долина: деревня, лес, вода, скалы, руины и северное святилище; оригинальная процедурная геометрия, инстансинг растительности, тени, туман и анимированные детали.
- Герой с оружием, щитом и анимациями движения, атаки, блока, получения урона и смерти. Камера двух видов учитывает препятствия.
- Физика Rapier с фиксированным шагом 60 Гц и интерполяцией отображения: гравитация, капсульные коллайдеры, ускорение/торможение, движение по рельефу, буфер прыжка/coyote time и столкновения со статическими препятствиями.
- Четыре противника-тени с патрулированием, преследованием, предупреждением об атаке, оглушением и возвращением на место. Один Хранитель с двумя фазами.
- Трёхударная последовательность лёгких атак с буфером следующего удара, тяжёлая атака, блок с возможностью пробития, парирование и уклонение. Есть здоровье, мана и выносливость. Снаряды проверяют весь пройденный за кадр отрезок, чтобы не проскакивать сквозь цель.
- Три заклинания: огненный снаряд, ледяной снаряд с оглушением и лечение. Есть расход маны, восстановление и эффекты попадания.
- Опыт, уровни, золото, три сундука с наградами, лечебные зелья и одно задание от NPC с отслеживанием прогресса.
- Три повторяемых улучшения по 40 золота: Warrior даёт +5 урона мечом, Mage — +8 урона атакующими заклинаниями и повышенное восстановление маны, Rogue — +15 максимальной выносливости.
- Главное меню, HUD, мини-карта, карта, журнал, инвентарь текущего снаряжения, окно улучшений, пауза, настройки качества/чувствительности/звука, экраны смерти и победы.
- Программно созданные музыка и звуки; переключатель звука. Сохранение/загрузка и автосохранение.
- День/ночь с 20-минутным внутренним циклом, луна/звёзды, контактное затемнение под объектами, Bloom на High/Ultra, пространственный LOD и объединение статической геометрии.
- Сохраняемые настройки Low/Medium/High/Ultra, FOV, чувствительности, эффектов камеры, Motion blur (по умолчанию выключен) и Adaptive resolution. Аппаратная частота кадров этой версии ещё не измерялась.

### Сохранения

Сохраняются позиция, здоровье/мана/выносливость, уровень и опыт, золото, зелья, улучшения, задание, побеждённые враги и открытые сундуки. Автосохранение происходит примерно каждые 30 секунд активной игры и после важных событий; также доступны `F5` и кнопка сохранения в паузе. **Begin journey начинает новое прохождение и перезаписывает единственный слот**; для продолжения выберите **Continue journey**.

Игровой формат v1 совместим с 0.1.0. Настройки изображения/камеры хранятся отдельно, в `eternal-realms-settings-v2`, и не перезаписывают игровой слот.

Прогресс хранится в `localStorage` внутри каталога пользовательских данных Electron, отдельно для учётной записи ОС. Обычно это `%APPDATA%/Eternal Realms` в Windows и `~/.config/Eternal Realms` в Linux; ОС может изменить базовый путь. Удаление данных приложения удаляет сохранение. Это локальные сохранения: Steam Cloud и синхронизация между компьютерами не подключены. Сохранение режима разработки в обычном браузере отдельно от настольного приложения.

## Проверки

```sh
npm test
npm run build
npm run test:e2e
```

Для версии 0.2.0 подтверждены **58 модульных тестов**, production-сборка и строгая проверка TypeScript. Проверки охватывают геометрию попаданий, блок, сохранения, реальный Rapier, движение/прыжки/уклонение, камеру и настройки. Это не аппаратный FPS-бенчмарк. Все четыре выбранных игровых сценария 0.2.0 прошли; бой/возрождение и комбо/парирование повторно проверены после исправлений.

Исторический отчёт предыдущего пролога остаётся в [docs/VALIDATION.md](docs/VALIDATION.md); он относится к 0.1.0. Для Playwright нужен системный Chromium либо браузер, установленный через `npx playwright install chromium`; путь можно задать в `PLAYWRIGHT_CHROMIUM_EXECUTABLE`. Это вспомогательная проверка рендерера; распространяемая игра запускается как настольное приложение.

На целевом устройстве отдельно проверьте: отображение сцены, движение и прыжок, столкновение со стеной, урон обоим участникам боя, смерть/возвращение, победу над Хранителем, повторное открытие приложения с сохранением, полноэкранный режим и отключение звука.

## Известные ограничения

Это небольшая одиночная локация и короткий пролог. Нет огромного открытого мира, двенадцати биомов, полноценных подземелий, погоды и сезонов. Динамический цикл дня/ночи реализован в 0.2.0. Есть один тип обычного врага и один босс; дракон, Король Мёртвых и остальные существа пока отсутствуют. Рельеф, анимации и AI рассчитаны на прототип, а не на фотореалистичную AAA-продукцию.

У героя один фиксированный набор снаряжения. Нет полноценного каталога предметов, смены оружия/брони, торговцев, разветвлённых диалогов, редактора внешности, распределения атрибутов и большого дерева навыков. Приседание замедляет движение и меняет позу, но не уменьшает физический коллайдер. Полная поддержка контроллеров, Steam Input, достижения, Steam Cloud и сетевой режим не реализованы. Звуки синтезируются, без записанных оркестровых композиций и озвучки.

Исходная версия сохранена локально в ветке `backup/pre-ultra-smooth-0.1.0` (коммит `1f6b501`); игровые сохранения v1 совместимы. [Заметки Ultra Smooth](docs/ULTRA-SMOOTH.md) содержат точные окна действий и таблицу пресетов.

План продолжения — в [docs/ROADMAP.md](docs/ROADMAP.md). Выпуск в Steam потребует отдельного тестирования целевых платформ, подготовки магазина и действий владельца Steamworks; готовность к релизной проверке Steam здесь не заявляется.

Подробный отчёт обновления: [VALIDATION-0.2.md](docs/VALIDATION-0.2.md).
