# Получение игры через GitHub

Пути `/workspace/...` относятся к облачной машине и сами по себе не создают
вложений или публичных ссылок для скачивания из чата.

После разрешённой записи проекта в GitHub workflow **Downloadable desktop game**
собирает Windows/Linux-версии и архив исходников. Запись в репозиторий и запуск
workflow ещё не выполнялись при подготовке этого файла.

1. Откройте свой репозиторий на GitHub и вкладку **Actions**.
2. Выберите **Downloadable desktop game**, затем успешный запуск.
3. В разделе **Artifacts** скачайте `Eternal-Realms-<номер запуска>`.
4. Распакуйте его; внутри находятся отдельные Windows/Linux-архивы и исходники.

Workflow также создаёт **черновик GitHub Release** с этими файлами. Владелец
репозитория может открыть его через **Releases**, скачать отдельный архив и
при желании самостоятельно опубликовать релиз. Черновик не становится публичным
релизом автоматически. Доступность исходников определяется видимостью репозитория.
Для скачивания приватных артефактов или черновика нужен вход в GitHub.

Для ручного повторного запуска: Actions → Downloadable desktop game → Run workflow.
Сборка использует встроенный краткоживущий `GITHUB_TOKEN`; передавать токен в чат
или сохранять пароль в файлах не требуется. Steam-публикация этим workflow не выполняется.

Если заключительный шаг создания черновика релиза отклонён политикой GitHub,
проверьте уже загруженные **Artifacts** того же запуска: этот шаг выполняется раньше.
