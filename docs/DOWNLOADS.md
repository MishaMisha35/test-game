# Получение игры через GitHub

Готовое настольное приложение скачивается из GitHub. Пути `/workspace/...` относятся к облачной машине и сами по себе не создают скачиваемых вложений в чате.

1. Войдите в GitHub и откройте [Actions репозитория](https://github.com/MishaMisha35/test-game/actions).
2. Выберите workflow **Downloadable desktop game**, затем успешный запуск для нужной версии. Точная ссылка на новый запуск указывается в сообщении о завершении обновления.
3. Внизу страницы, в разделе **Artifacts**, скачайте `Eternal-Realms-<номер запуска>`.
4. Распакуйте скачанный архив. Для Windows выберите вложенный `Eternal-Realms-2.1.0-Windows-x64.zip`, для Linux — `Eternal-Realms-2.1.0-Linux-x64.tar.gz`. `Source.zip` содержит исходники, а не готовую игру.
5. Полностью распакуйте архив своей платформы в отдельную папку. Windows: запустите `Eternal Realms.exe`; Linux: `./"Eternal Realms"`.

Сохраняйте все подпапки рядом с исполняемым файлом. Устанавливать Unity, другой движок, Node.js или отдельный браузер для запуска не требуется. Workflow хранит Actions-артефакты 30 дней; после истечения срока сборку можно повторить.

Workflow также создаёт **черновик GitHub Release** с отдельными архивами и `SHA256SUMS.txt`. Владелец репозитория может скачать их через **Releases** и самостоятельно опубликовать релиз. Черновик не становится публичным релизом автоматически. Для скачивания Actions-артефактов и черновика нужен вход в GitHub; видимость исходников определяется настройками репозитория.

Для повторной сборки: Actions → Downloadable desktop game → Run workflow. После завершения проверяйте версию в имени вложенного архива. Сборка использует встроенный краткоживущий `GITHUB_TOKEN`; передавать токен в чат или сохранять пароль в файлах не требуется. Steam-публикация этим workflow не выполняется.

Если создание черновика отклонено политикой GitHub, проверьте уже загруженные **Artifacts** того же запуска: загрузка файлов выполняется раньше.
