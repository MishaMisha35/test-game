# Eternal Realms 0.2.0 — Ultra Smooth

Версия 0.2.0 улучшает управление, бой, камеру и оформление существующего настольного пролога. Сохранены поселение, NPC, старые руины, четыре тени, Хранитель, три сундука и задание. Проверка исходных данных подтвердила сохранность **275 препятствий и пяти интерактивных объектов**. Дополнительная растительность и свет не переносят объекты задания.

## Движение и камера

Физика выполняется с фиксированным шагом 60 Гц. Отрисовка интерполирует положение героя, врагов и снарядов между физическими шагами. Ускорение, остановка и поворот ограничены по времени; движение по диагонали нормализовано. Шаги и анимация опираются на фактическое перемещение, а не только на нажатую клавишу. Добавлены наклон при разгоне/повороте, переходы ходьбы и бега, реакция на приземление и след оружия.

| Управление              | Результат                                                                    |
| ----------------------- | ---------------------------------------------------------------------------- |
| WASD / стрелки          | Движение относительно камеры                                                 |
| CapsLock                | Переключение ходьбы; обычный бег остаётся режимом по умолчанию               |
| Shift                   | Спринт с расходом выносливости                                               |
| Space                   | Прыжок: 0,10 с допуска после схода с края и 0,12 с буфера перед приземлением |
| Ctrl                    | Приседание/медленное движение; физическая капсула сохраняет размер           |
| ПКМ + мышь              | Поворот камеры и удержание щита                                              |
| Двойной щелчок по сцене | Захват мыши; Esc освобождает её                                              |
| Колесо мыши             | Дистанция камеры 2,8–10 м                                                    |
| B                       | Смена плеча камеры                                                           |
| V                       | Первый / третий вид                                                          |
| Z / C                   | Поворот камеры с клавиатуры                                                  |

Поворот камеры сглаживается экспоненциально. Положение следует за интерполированным героем. Столкновения проверяются движущейся сферой, покрывающей ближнюю плоскость камеры: при стене камера втягивается сразу, выходит обратно плавно, затем повторно проверяет итоговую позицию. Коллайдер героя и другие актёры не блокируют обзор. В первом лице нет покачивания головы.

## Бой

- ЛКМ или R — лёгкий удар; Shift + ЛКМ/R — тяжёлый.
- Три лёгких удара образуют последовательность. Следующий удар можно нажать в конце текущего: окно постановки в очередь — последние 0,26 с, буфер — 0,25 с. Возможность продолжения последовательности после удара сохраняется 0,30 с.
- ПКМ удерживает блок. Начало блока открывает **окно парирования 0,16 с**: герой должен смотреть на врага; круговой удар Хранителя не парируется. Успех оглушает противника и не наносит герою урон.
- Q — уклонение на **4,2 м за 0,38 с** в свободном пространстве. Препятствия сокращают путь. Неуязвимость действует только с 0,06 до 0,26 с уклонения; расход — 22 выносливости, восстановление — 1,1 с.
- Попадания по-прежнему проверяют дистанцию, направление, высоту и препятствия. Добавлены короткая остановка при попадании, ограниченный импульс камеры, искры, след клинка и звуки парирования/приземления.

Заклинания и прогресс пролога сохранены: 1/2 выбирают огонь/лёд для F, 3 сразу лечит за ману, H расходует зелье. E взаимодействует с NPC, сундуками и святилищем.

## Качество изображения

Настройки открываются кнопкой шестерёнки. Их можно менять без перезапуска.

| Пресет | Максимальный pixel ratio* | Карта теней | Bloom    | Лимит боевых частиц |
| ------ | ------------------------- | ----------- | -------- | ------------------- |
| Low    | 0,85                      | Выключена   | Выключен | 80                  |
| Medium | 1,15                      | 1024        | Выключен | 150                 |
| High   | 1,50                      | 1536        | Включён  | 230                 |
| Ultra  | 1,75                      | 2048        | Включён  | 320                 |

\* Верхняя граница дополнительно ограничена `devicePixelRatio` экрана; это множитель разрешения рендеринга, а не размер окна. Пресеты также меняют дальность/плотность мелкой растительности, количество звёзд и декоративные эффекты. Большие деревья и повторяющиеся детали разбиты на пространственные группы для отсечения и LOD; статическая архитектура объединяется по материалам.

Есть мягкое **контактное затемнение под объектами** (процедурные контактные тени); SSAO-прохода нет. Используются PBR-материалы, тональное отображение, туман, анимированная вода и растительность, светлячки и мягкие лучи света. Полный цикл солнца, сумерек, ночи, луны и звёзд занимает **20 минут внутренних часов мира**.

Доступны базовый FOV 50–90°, чувствительность камеры 0,3–2, интенсивность эффектов камеры, Motion blur и Adaptive resolution. Motion blur **по умолчанию выключен**; это необязательное экранное размягчение движения камеры. Расширение FOV при спринте ограничено +7° при интенсивности 1. Интенсивность эффектов камеры 0 отключает тряску и расширение FOV при спринте. Motion blur управляется отдельным переключателем.

Adaptive resolution включён по умолчанию. После начального прогрева он постепенно снижает или повышает внутреннее разрешение в пределах выбранного пресета: нижний предел — pixel ratio 0,65 либо меньшая граница экрана; верхний — максимум пресета/экрана. Это способ ограничить нагрузку. Он **не гарантирует 60 FPS** на любом оборудовании; аппаратного GPU-бенчмарка этой версии пока нет. При медленной работе начните с Low, выключенного Motion blur и уменьшенного размера окна.

## Сохранения и исходная версия

Игровое сохранение формата **v1 совместимо с 0.1.0**. Настройки графики и камеры записываются отдельно в `eternal-realms-settings-v2` и не заменяют прогресс. Сохраняются качество, чувствительность, FOV, интенсивность эффектов, Motion blur и Adaptive resolution. Ошибка записи в локальное хранилище не останавливает игру.

До изменений сохранена локальная ветка `backup/pre-ultra-smooth-0.1.0`, коммит `1f6b501`. Она содержит исходный пролог. Для безопасного просмотра отдельного файла можно использовать:

```sh
git show backup/pre-ultra-smooth-0.1.0:src/game/GameManager.ts
```

## Что проверено

Для 0.2.0 подтверждены production-сборка, строгая проверка TypeScript и **58 модульных тестов**, включая реальные проверки Rapier, движения, камеры и настроек. Четыре выбранных сквозных сценария прошли; два затронутых финальными исправлениями сценария повторно пройдены. Отчёт [VALIDATION.md](VALIDATION.md) относится к исторической версии 0.1.0.

Windows-версия требует запуска на настоящем Windows-компьютере. Облачный программный рендеринг не определяет минимальные системные требования или частоту кадров на игровом GPU. Проверка Steam-клиента и Steam Deck, Steamworks-службы и публикация в Steam остаются отдельной работой. Масштаб мира и RPG-системы сохраняют статус игрового пролога.

Подробный отчёт обновления: [VALIDATION-0.2.md](VALIDATION-0.2.md).
